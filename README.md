# Gustavo Santana | Full Stack Developer

Este é o repositório do meu **Portfólio Pessoal**, uma aplicação web desenvolvida para apresentar minha trajetória, habilidades técnicas e projetos como desenvolvedor Full Stack. O site foi construído com foco em alta performance, design responsivo e uma experiência de usuário impecável.

## 🚀 Sobre o Projeto

O objetivo deste projeto foi criar um site institucional moderno, com arquitetura sólida, que servisse como um cartão de visitas digital interativo. Desenvolvido com uma abordagem *mobile-first*, ele destaca:

*   **Design Bento-Grid:** Organização eficiente de informações.
*   **Interatividade:** Animações de scroll e menus responsivos.
*   **Performance:** Código limpo e otimizado para carregamento rápido.

## 🛠️ Tecnologias Utilizadas

O projeto utiliza uma combinação de tecnologias modernas para garantir escalabilidade e um visual profissional:

*   **Estrutura & Estilização:** HTML5, CSS3 (com variáveis CSS e design responsivo)[cite: 1].
*   **Interatividade:** JavaScript moderno (ES6+) para manipulação de DOM e lógica de formulário[cite: 1].
*   **Integrações:** API FormSubmit para gerenciamento de contatos e integração com WhatsApp[cite: 1].
*   **Design & Ativos:** Ícones via Devicon, fontes do Google Fonts e prototipagem com Figma[cite: 1].

## ✨ Funcionalidades

*   **Navbar Dinâmica:** Efeito de transição ao rolar a página[cite: 1].
*   **Formulário de Contato:** Validação e envio de mensagens sem recarregar a página (com feedback visual para o usuário)[cite: 1].
*   **Menu Mobile:** Navegação intuitiva para dispositivos móveis[cite: 1].
*   **Animações de Scroll:** Elementos que revelam conteúdo conforme a rolagem do usuário[cite: 1].
